# Рефакторинг баз данных и приложений

## Второй этап рефакторинга

### Задание на этап

Этап 2. Интеграционное тестирование

Цель: Обеспечить высокую надежность и стабильность работы приложения путем внедрения комплексного интеграционного тестирования, максимально приближенного к реальным условиям.

Задачи:
- Написание набора интеграционных тестов с использованием Testcontainers для точного воспроизведения рабочей среды, включая базы данных.
- Доработка кодовой басы для обеспечения возможности проведения изолированного и эффективного интеграционного тестирования.
- Исправление дефектов и устранение узких мест, выявленных в процессе интеграционного тестирования.
