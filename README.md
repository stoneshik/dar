# Рефакторинг баз данных и приложений

## Третий этап рефакторинга

### Задание на этап

Этап 3. Оптимизация использования индексов

Цель: Проанализировать использование индексов на большом объеме данных (минимум 1 Гб), проверить действительно ли есть прирост в производительности от их использования и на основе проведенного анализа удалить ненужные индексы и оставить/добавить нужные.

Задачи:

1. Написание скрипта SQL, который генерирует большой объем тестовых данных для всех таблиц в базе данных.
2. Написать скрипты, которые позволяют оценить использование индексов, после того как база данных заполнена сгенерированными данными.
3. Последовательно проанализировать каждый используемый индекс, изменить его тип при необходимости, удалить в случае если он не дает значимого прироста в производительности.
4. Проверить корректность внесенных изменений, составив результирующую таблицу для всех используемых индексов.
