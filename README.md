# Рефакторинг баз данных и приложений

## Первый этап рефакторинга

### Задание на этап

Этап 1. Архитектурный рефакторинг и обновление зависимостей

Цель: Провести модернизацию и оптимизацию бэкенд-архитектуры приложения для повышения его производительности, безопасности, поддерживаемости и соответствия современным стандартам.

Задачи:
1. Обновить версии ключевых зависимостей (Spring Boot, Java и др.) до максимально стабильных и совместимых релизов для улучшения производительности и безопасности.
2. Выполнить листенинг и, при необходимости, доработать код для корректной работы с новыми версиями библиотек.
3. Провести архитектурный рефакторинг эндпоинтов для приведения их в соответствие с принципами REST.
4. При необходимости, реорганизовать структуру модулей проекта для уменьшения связанности (снижение coupling) и повышения читаемости кода.
